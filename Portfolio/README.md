# macOS Themed Portfolio Website

A modern, sleek portfolio website built with Next.js, featuring a macOS-inspired design aesthetic. This project combines modern web technologies with the iconic visual language of macOS to create an engaging, interactive personal portfolio.

## ✨ Features

- **macOS Design Language**
  - Window-style draggable components with traffic light window controls
  - System-inspired typography and spacing
  - Dock-like navigation with smooth scaling hover animations
  - Menu bar with live time, date, battery level, wifi status, and wallpaper selector
  - Built-in Terminal with interactive commands
  - Built-in Music Player, Code Editor, and Gemini AI Chat

- **Technical Highlights**
  - Built with Next.js for high performance and SEO
  - Fully responsive design (Desktop, Tablet, Mobile)
  - Dynamic light/dark theme switching
  - Interactive apps & windows (About Me, Projects, Work Experience, Contact, Terminal, VS Code)

## 🛠️ Technologies Used

- Next.js
- React
- Tailwind CSS
- TypeScript
- Lucide React

## 📦 Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/usp13/mac-os-portfolio-utsav.git
```

2. Navigate to the project directory:
```bash
cd mac-os-portfolio-utsav/Portfolio
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
